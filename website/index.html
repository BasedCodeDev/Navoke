01 Browser workflows for people and agents

Let agents invoke the web.

Navoke turns work you already do in signed-in websites into reusable workflows for agents. It saves the files and results when each run is done.

03 Built for real browser work

Agents build their own workflows.

Agents can combine steps, try them, fix problems, and reuse what works. Navoke keeps every run visible and puts the results where you can find them.

session / 01

Use the account you already have

Use a separate saved browser session or the Chrome window where you are already signed in.

instructions / 02

Give agents clear instructions

Each workflow says what it needs, what it will do, and what it gives back.

control / 03

Pause where people matter

When a login or verification needs you, the workflow pauses clearly and continues when you are ready.

history / 04

See what happened

A clear history of steps, messages, screenshots, and errors helps you find and fix problems.

results / 05

Keep every useful result

Files and other results stay on your machine, organized with the run that created them.

reuse / 06

Run successful work again

Save a working setup to your workflow library and start it again from Navoke or the command line.

06 Local by design

Your browser stays yours. The repeated work becomes reusable.

Your workflow history, files, and browser sign-ins stay on your machine. Navoke organizes the work without sending it to a hosted automation service.

  • Your data stays on your device
  • Results stay organized by project
  • Browser sessions can stay signed in
  • Install only the plugins you choose
