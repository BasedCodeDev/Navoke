01 Agent-native browser workflow runtime

Let agents invoke the web.

Navoke turns authenticated browser procedures into typed, resumable tools that return durable artifacts.

02 The core loop

Browser work should be callable.

Define the procedure once. Navoke gives people, scripts, and agents the same explicit contract for running it again.

  1. 01 / define

    Describe the work

    Typed input and output schemas turn a procedure into a tool that can explain what it needs.

  2. 02 / invoke

    Start it anywhere

    Run the same workflow from the desktop app, a JSON CLI call, or an agent operating through the CLI.

  3. 03 / observe

    See real progress

    Follow steps, events, screenshots, and traces instead of waiting on a browser with no usable state.

  4. 04 / return

    Keep the result

    Files, models, logs, and structured outputs are registered as durable, inspectable artifacts.

03 Proof built into every run

Agents build their own workflows.

Typed contracts, observable runs, and durable artifacts give agents the structure to compose, test, repair, and reuse their own browser pipelines.

session / 01

Use the account you already have

Run in a persistent Playwright profile or through the companion controller in your normal Chrome session.

contract / 02

Give agents a typed surface

Zod schemas, stable manifests, and JSON output make capabilities discoverable without teaching every click.

control / 03

Pause where people matter

Login, verification, and account checks become explicit manual states that can safely resume.

evidence / 04

Inspect what actually happened

Steps, events, traces, screenshots, and structured errors give workflow authors evidence instead of guesswork.

output / 05

Return more than a click

Every useful output is stored locally and registered with its run for preview, reuse, and traceability.

reuse / 06

Keep proven procedures close

Save successful run configurations to the workflow library and invoke them again from the app or CLI.

05 For workflow authors

06 Local by design

The browser can stay human. The workflow becomes a tool.

Runs, inputs, outputs, traces, and browser profiles stay on your machine. Navoke adds a structured execution layer without moving the work to a hosted automation service.

  • Local API and SQLite metadata
  • Project-root run folders
  • Persistent browser profiles
  • User-installed workflow plugins
